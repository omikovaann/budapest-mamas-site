# Budapest Mamas Guide — public code mirror

Гайд для русскоязычных мам в Будапеште — клиники, роды, пособия, документы.
Сайт: https://budapest-mamas.netlify.app

**Это публичное зеркало только кода сайта** (`website/`) и документации (`docs/`).
Полный проект (обработка чата, приватные черновики) — в приватном репозитории
`budapest-mamas`. Этот репозиторий существует отдельно и публично специально,
чтобы Claude.ai мог читать файлы сайта напрямую через raw.githubusercontent.com.

Архитектура всего проекта и последние изменения: [`docs/architecture.md`](docs/architecture.md)

## Структура

```
website/   — сайт гайда (деплоится на Netlify, автодеплой из приватного репо)
docs/      — документация проекта
```
